# 📚 Bookverse

Bookverse is a sleek and intuitive mobile application that allows users to browse and search for books using the Google Books API. Whether you're looking for your next favorite novel or researching a topic, Bookverse makes discovering books effortless and enjoyable.

---

## ✨ Features

- 🔍 Search Books: Find books by title or keyword using the Google Books API.

- 📖 Free Previews: View free previews of books directly within the app.

- 🧭 Browse Results: Explore search results with clean, responsive design.

- 💡 Book Details: Access key information like author, publisher, description, and more.

---

## 🛠️ Tech Stack

- **Framework:** Flutter  
- **State Management:** Flutter Bloc / Cubit  
- **API:** Google Books API
